# Master-of-Research-COMP8990
Code for the MRes thesis “Distilling Graph Intelligence for Urban Traffic Digital Twins Deployment”: compares GCN+GRU and STGCN teachers, a graph-free MLP+GRU and distilled students against a persistence baseline on one-step traffic-flow forecasting in IUTF data, with accuracy, training time, latency, size and memory results.
